# Pilot report: module analysis from page four

Pages 1-3 remain project summary, inspection methods, and exactly one flight overview page.

From page 4, each reviewed finding is shown **once**, numbered in report order:
- **Befund NN – Modul-ID** (do not confuse a finding number with the number of inspected modules).
- Expert-reviewed observation, without claiming a proven electrical cause from a thermal hotspot.
- RGB and thermal source imagery side by side where supplied; frame IDs and geometry provenance below.
- Missing images explicitly marked as not recorded; never synthesize customer evidence.

The total/conspicuous module counts on page 1 come from project counts, **not** the number of findings or photos. Module identity and unique-count verification are upstream responsibilities.

Keep each module's heading, observation, image pair and caution together where possible. Multiple findings can span subsequent pages; no arbitrary one-module-per-page rule.

The report and its fictional CLI sample are local only. Customer imagery must not be uploaded, transmitted or released without authorization. The sample illustration is not evidence of an inspection.
