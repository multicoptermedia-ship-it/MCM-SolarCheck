# Offline-first report pilot

Prioritize offline inspection and report generation. Keep the inspection and reporting core reusable by the online application. The initial customer report is inspired by DIN IEC/TS 62446-3 (VDE V 0126-23-3):2018-04, without claiming conformity. Show a reviewed draft to a customer only with permission, collect feedback, and revise the template. Unknown measurements remain unknown. No automated customer delivery.
