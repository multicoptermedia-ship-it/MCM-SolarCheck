# Customer pilot report review

The offline report is the first product acceptance milestone. Keep the report core shared with online; login, payment and online delivery remain separate adapters.

Before sharing, obtain customer authorization for any project-specific images and report contents. Use a reviewed sample with clearly marked missing measurements. Ask the customer about readability, finding locations, evidence images, recommendations, report length and terminology. Record feedback without exposing customer identifiers in public issues. Revise a versioned template before assessing a separately verified normative report variant.

Current limitations: report content contract is not yet wired into the existing PDF/DOCX/ODT exporters. The local training export inventory tracks registered crops only; it does not automatically cover backups, copied files, model weights or concurrent exports. Do not claim comprehensive withdrawal enforcement.
