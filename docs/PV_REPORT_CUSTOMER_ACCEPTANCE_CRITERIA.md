# First customer-facing report acceptance criteria

1. Offline report is generated from an explicitly reviewed inspection, not an AI-only hypothesis.
2. Report displays project, inspection date, inspector, plant, measurement conditions or 'nicht erfasst', and limitations.
3. Module observations are clearly distinguished from verified electrical diagnoses.
4. RGB and thermal evidence is traceable to original frame identifiers, with actual images included only after validating local file availability and review.
5. The document clearly states 'in Anlehnung an' DIN IEC/TS 62446-3, with no assertion of full normative compliance.
6. Customer must explicitly authorize external sharing of their own inspection content.
7. Obtain and log customer feedback on layout, findings, readability and recommendations; update template versions.
8. Keep all shared inspection and report logic usable by online mode without importing payment or login into offline mode.

The initial pilot PDF is not yet a complete customer-ready inspection report.
